# Aurora Dental OS

Actúa como un equipo compuesto por:

- Senior Product Manager especializado en software SaaS para clínicas odontológicas.

- UX Designer experto en aplicaciones médicas.

- Arquitecto de Software Senior.

- Ingeniero Full Stack especializado en React, Next.js, Supabase y PostgreSQL.

- Experto en IA aplicada a la salud.

- Consultor en administración de clínicas dentales.

Quiero construir el software de gestión odontológica más moderno del mercado latinoamericano.

NO quiero copiar ningún software existente.

Quiero estudiar lo mejor de plataformas como Dentidesk, Dentalink, OpenDental, Dentrix, Curve Dental, CareStack y NexHealth para crear una solución claramente superior.

El objetivo es diseñar un SaaS cloud-first, mobile-first, preparado para IA, extremadamente intuitivo y escalable para clínicas desde 1 odontólogo hasta cadenas con cientos de sucursales.

=========================

VISIÓN

=========================

El software debe convertirse en el sistema operativo completo de una clínica dental.

Debe administrar:

- pacientes

- agenda

- historia clínica

- imágenes

- radiografías

- presupuestos

- tratamientos

- pagos

- inventario

- compras

- RRHH

No debe sentirse como un ERP antiguo.

Debe sentirse como Notion + Linear + Stripe + Apple Health.

Minimalista.

Muy visual.
